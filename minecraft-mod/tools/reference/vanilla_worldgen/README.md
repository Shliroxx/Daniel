# Vanilla-Weltgenerierung (Minecraft 1.21.1)

Unveränderte Kopien der Vanilla-Dateien `data/minecraft/worldgen/{density_function,noise,noise_settings}` aus dem
Minecraft-1.21.1-Jar (nur Overworld, Amplified, Large Biomes). Quelle für `tools/generate_planet_worlds.py`: jede Welt
bekommt daraus eigene, umbenannte Kopien (`kingdomomnitrix:<welt>/...`). Minecraft leitet jedes Rauschfeld aus seinem
Namen ab — umbenannte Kopien ergeben deshalb auf jeder Welt völlig anderes Gelände bei gleicher Vanilla-Qualität.
Nicht von Hand ändern; zum Aktualisieren aus dem Jar der passenden Minecraft-Version neu kopieren.
